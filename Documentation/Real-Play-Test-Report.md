## 1. Testing Philosophy & Strict Acceptance Rule

> [!IMPORTANT]
> **Honest Evidence Policy**
> - A successful compilation does **NOT** prove the launcher works.
> - A successful launcher screenshot does **NOT** prove Rules of Survival (`ros.exe`) starts.
> - A successful process launch of `ros.exe` does **NOT** prove the game reaches its main menu.
> - A rendered main menu does **NOT** prove multiplayer gameplay works.
> - **We never fabricate, manipulate, or substitute mockups for genuine runtime evidence.**

### D. REAL ROS GAME CLIENT INTEGRATION STATUS
- **Verdict:** **BLOCKED / NOT TESTED (Awaiting Authorized Test Machine & Server Emulation)**
- **Technical Reality:**
  - `ros.exe` is a 64-bit NeoX engine client that loads `assets.npk` and `script.npk`.
  - Upon startup, `ros.exe` reaches out to NetEase login gateway endpoints (`h45na.prot`, `NEACSDK`).
  - Because official NetEase servers are permanently offline, launching unpatched `ros.exe` directly results in a network timeout / connection error dialog.
  - **Compliance Guardrail:** ROS Revival will not modify `ros.exe` or bypass anti-cheat mechanisms. We will document connection behavior honestly as authentic evidence is collected on Windows test machines.
